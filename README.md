# Help Desk — Gestió de l'assistència tècnica informàtica
Projecte Intermodular SMX

Disseny d'un servei d'assistència tècnica per a una empresa d'informàtica.
L'objectiu és millorar la comunicació entre departaments i organitzar la recepció,
l'assignació i la resolució de les incidències dels clients.

## Autor
- LORENA (@arimoi2)

## Rols simulats
- **Rol A — Coordinació i documentació:** organitzar les tasques i redactar la documentació del projecte.
- **Rol B — Servei tècnic i reparacions:** definir els procediments de diagnòstic i reparació dels equips.
- **Rol C — Sistemes i xarxes:** definir els procediments de suport relacionats amb els sistemes operatius i les xarxes.

## Contingut del repositori
- `documents/` — Document de Repte (Annex A).
- `documents/fitxes/` — Fitxes d'activitat (Annex B).
- `configuracio/` — Configuracions tècniques (quan s'execute el projecte).
